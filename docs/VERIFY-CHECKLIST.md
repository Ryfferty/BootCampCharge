# BootCampCharge v0.4.0 部署验证清单

> 按顺序逐项验证。每项标 ✅ 或 ❌。
> 前置条件：充电器已连接、InpOut 驱动已启动（`sc start inpoutx64`）。

---

## 第一阶段：基础启动（必须全过）

### ✅ 1.1 程序正常启动
**操作**：双击 BootCampCharge.exe（或管理员运行）
**通过**：托盘出现闪电图标，无弹窗报错，任务管理器有 BootCampCharge 进程
**失败**：弹窗"InpOut 驱动未加载" / "启动失败" / 进程闪退

### ✅ 1.2 左键托盘图标打开主窗口
**操作**：左键单击托盘闪电图标
**通过**：弹出标准窗口（标题 BootCampCharge），有电池图标、电量百分比、滑块、设置项
**失败**：无反应 / 弹出错误 / 窗口无法缩放

### ✅ 1.3 窗口可缩放（不是弹窗）
**操作**：拖动窗口右下角放大
**通过**：窗口可以自由缩放，标题栏有三按钮（最小化/最大化/关闭），任务栏有图标
**失败**：不能缩放 / 只有 X 按钮 / 任务栏无图标

### ✅ 1.4 关闭窗口 = 最小化到托盘
**操作**：点窗口 X 按钮
**通过**：窗口消失但进程还在托盘运行（任务管理器有进程）
**失败**：程序完全退出 / 弹出确认对话框

---

## 第二阶段：充电限制 BCLM（核心功能，已验证可用）

### ✅ 2.1 设置充电限制生效
**操作**：拖滑块到 80%，或右键托盘→充电限制→80%（推荐）
**预期**：SMC 的 BCLM 被写成 80
**验证方法**：观察电量——如果当前电量 > 80%，电量应该逐渐下降或停止充电
**通过**：电量不再上升，停在 80% 附近（±1%）
**失败**：电量继续上升到 100%

### ✅ 2.2 滑块和输入框联动
**操作**：拖滑块 → 看输入框数字；改输入框数字 → 看滑块位置
**通过**：两者同步变化，数字范围 20-100
**失败**：不同步 / 输入框不更新

### ✅ 2.3 充电限制持久（退出后仍生效）
**操作**：设限制 80% → 退出程序 → 重新插拔充电器
**通过**：电池仍然最多充到 80% 附近（BCLM 是硬件持久的）
**失败**：电池充到 100%（说明 BCLM 被清了）

## 第三阶段：UI 信息显示

### ✅ 3.1 电量百分比显示正确
**操作**：对照 Windows 任务栏电池图标百分比
**通过**：BootCampCharge 显示的百分比 = Windows 显示的百分比
**失败**：显示 --% / 百分比不一致

### ✅ 3.2 CPU 温度显示
**操作**：看主窗口"CPU XX°C"
**通过**：显示合理温度（35-70°C 范围）
**失败**：空白 / 显示 0°C / 显示异常值（如 128°C）

### ✅ 3.3 电池健康信息
**操作**：看"电池信息"卡片
**通过**：健康度 ~78%（设计容量 ~66000 mWh，当前最大 ~51680 mWh），电压有值（~12000 mV）
**失败**：全部显示 -- / 健康度 0%

### ✅ 3.4 适配器状态
**操作**：拔掉充电器 → 看适配器状态；插回 → 看状态
**通过**：拔掉显示"未连接"，插回显示"已连接"
**失败**：状态不变化

---

## 第四阶段：临时充满 TopUp（BCLM 模式，不依赖 CH0B）

### ✅ 4.1 启动临时充满
**操作**：设限制 80% → 点"临时充满"按钮（或右键→临时充满）
**预期**：BCLM 被写成 0（解除限制），电池开始充向 100%
**通过**：
- 按钮文字变成"停止充满"
- 托盘状态显示"临时充满中"
- 电量开始上升（如果当前 < 100%）
**失败**：电量不上升 / 按钮文字不变

### ✅ 4.2 停止临时充满
**操作**：临时充满中 → 点"停止充满"
**预期**：BCLM 恢复成用户设定值（如 80%）
**通过**：
- 按钮文字变回"临时充满"
- 如果电量已超过 80%，电量不再上升
**失败**：电量继续充到 100%（说明 BCLM 没恢复）

### ✅ 4.3 ★ 临时充满时退出 → 充电限制恢复
**操作**：设限制 80% → 点临时充满 → **不要停止** → 直接退出程序（右键→退出）
**预期**：BCLM 从 0 恢复成 80
**验证方法**：退出后重新插拔充电器，观察电池是否最多充到 80%
**通过**：退出后充电限制仍然生效（最多 80%）
**失败**：退出后电池充到 100%（说明 BCLM 留在 0 了——这就是审计修复的 bug）

## 第五阶段：设置项事件绑定（审计修复的关键 bug）

### ✅ 5.1 过热保护开关
**操作**：勾选"过热保护" → 退出程序 → 重新启动 → 看是否还是勾选状态
**通过**：重启后仍勾选（配置已保存）
**失败**：重启后未勾选（说明事件没绑定，配置没保存）

### ✅ 5.2 过热温度选择
**操作**：勾选过热保护 → 下拉选 45°C → 退出 → 重启
**通过**：重启后过热保护勾选 + 下拉显示 45°C
**失败**：重启后下拉回到默认 40°C

### ✅ 5.3 航行模式开关
**操作**：勾选"航行模式" → 退出 → 重启
**通过**：重启后仍勾选
**失败**：重启后未勾选

### ✅ 5.4 自动放电开关
**操作**：勾选"自动放电" → 退出 → 重启
**通过**：重启后仍勾选
**失败**：重启后未勾选

### ✅ 5.5 开机自启
**操作**：勾选"开机自启" → 检查注册表
**验证方法**：Win+R → `regedit` → `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` → 找 BootCampCharge 键
**通过**：注册表有 BootCampCharge 键值指向 exe 路径
**失败**：注册表无此键

## 第六阶段：CH0B 依赖功能（放电/过热/航行/校准）

> ⚠️ 这些功能依赖 CH0B，在 Boot Camp 下可能部分可用或不可用。
> 即使部分失败也不影响核心充电限制功能（第二阶段）。
> 这里是**探查**，不是必须全过。

### ✅ 6.1 手动放电
**操作**：电量 > 50% → 点"放电"按钮
**预期**：BCLM 先清 0，CH0B 写 2（禁止充电），电池开始下降
**通过**：
- 按钮变"停止放电"
- 托盘图标变橙色
- 电量开始下降（可能需要等 1-2 分钟才看到变化）
**失败**：电量不下降 / 按钮不变

### ✅ 6.2 停止放电 → 充电限制恢复
**操作**：放电中 → 点"停止放电"
**预期**：CH0B 写 0（恢复充电），BCLM 恢复用户设定值
**通过**：
- 电量不再下降
- 如果电量 < 限制值，开始充电
- 之后电量不超过限制值（如 80%）
**失败**：不充电了（电量一直降）/ 充到 100%

### ✅ 6.3 过热保护触发
**操作**：勾选过热保护 → 选 35°C（低阈值容易触发）→ 正常用电脑让 CPU 升温
**预期**：CPU 温度超过 35°C 时停止充电
**通过**：温度超过 35°C 后，状态显示"⚠ 过热保护 冷却中"，托盘变红色，电量停止上升
**失败**：温度超过 35°C 仍继续充电

### ✅ 6.4 过热保护恢复
**操作**：过热保护触发后 → 等 5 分钟（让 CPU 冷却到 35°C 以下）
**预期**：5 分钟冷却后恢复充电
**通过**：状态从"冷却中"→"恢复充电中"→ 正常
**失败**：一直停在冷却中 / 恢复后又立刻触发

### ✅ 6.5 航行模式
**操作**：设限制 80% → 勾选航行模式 → 电量充到 80% 以上
**预期**：电量到 80% 停止充电，电量下降到 50%（下限）才恢复充电
**通过**：
- 电量到 80% → 停充
- 电量降到 50% → 恢复充电
- 50-80% 之间不操作
**失败**：到 80% 后不充电了（81% 不充电 bug）/ 在区间内频繁充停

## 部署步骤（验证前操作）

```
1. 杀旧进程（管理员）：
   PowerShell: Stop-Process -Name BootCampCharge -Force

2. 部署新版本（拷贝整个 bin/Release 目录）：
   cp -rf ~/projects/bootcamp-charge-csharp/bin/Release/* /mnt/c/Users/r''y''z/Desktop/BootCampCharge最新版/

3. 启动 InpOut 驱动（管理员）：
   sc start inpoutx64

4. 运行：
   双击 BootCampCharge.exe（会弹 UAC，点是）
```
